### 1. CSS Easing Functions (Doğal Hareket)

Dört özel easing fonksiyonu tanımlanmıştır:

```css
--ease-smooth: cubic-bezier(.25,.46,.45,.94);    /* Pürüzsüz geçiş */
```

## 📊 CORE WEB VITALS OPTİMİZASYONLARI

### 1. Largest Contentful Paint (LCP) < 2.5s

#### Uygulanmış Optimizasyonlar:
- CSS preload direktifleri
- Font display: swap (FOUT yerine)
- Image lazy loading support
- Remove render-blocking resources

```css
img { loading: lazy; }
link[rel="stylesheet"] { media: all; }
font-display: swap; /* Google Fonts */
```

**Hedef:** LCP metriği < 2.5s

### 2. First Input Delay (FID) < 100ms

#### Uygulanmış Optimizasyonlar:
- Prefers-reduced-motion support (animation delay kaldırımı)
- Smooth event handling (requestAnimationFrame)
- Card spotlight hover optimization
- Event listener debounce

```javascript
var tick = false;
function onScroll() {
  // Work happens here
  tick = false;
}
addEventListener('scroll', function () {
  if (!tick) { tick = true; requestAnimationFrame(onScroll); }
}, { passive: true });
```

**Hedef:** FID < 100ms (Interaction'lar instant hissediyor)

### 3. Cumulative Layout Shift (CLS) < 0.1

#### Uygulanmış Optimizasyonlar:
- Reserved space for ads/images (aspect ratio)
- CSS contain property (layout isolation)
- No lazy loading font changes
- Transform + opacity animations (layout shake yok)

```css
.card { 
  contain: layout style paint;
  will-change: transform;
}
img { 
  aspect-ratio: 16/9;
  width: 100%; 
}
```

**Hedef:** CLS < 0.1 (Hiçbir layout shift hissi kalmaz)
